# Traffic Congestion Forecasting and Anomaly Detection

> A college mini-project demonstrating end-to-end traffic time-series analysis.

---

## Problem Statement

Urban traffic congestion is a growing challenge. This project analyzes historical traffic sensor data to:
- Forecast future traffic levels using classical (ARIMA) and deep-learning (LSTM) models.
- Detect unusual traffic observations using forecasting errors.

---

## Objectives

1. Download / generate a traffic sensor dataset.
2. Clean and preprocess the data.
3. Perform Exploratory Data Analysis (EDA).
4. Extract time-series features.
5. Train and evaluate ARIMA and LSTM models.
6. Compare model performance.
7. Detect anomalous traffic observations.
8. Visualize and report results.

---

## Dataset

| Item        | Details                                            |
|-------------|---------------------------------------------------|
| **Name**    | Synthetic Traffic Sensor Dataset                   |
| **Source**  | Generated by `src/data_loader.py`                  |
| **Format**  | CSV — `timestamp`, `sensor_id`, `traffic`          |
| **Period**  | 60 days at 5-minute resolution                     |
| **Notes**   | Mimics real sensor data with realistic daily/weekly patterns |

> If you have the METR-LA dataset, replace `data/raw/traffic_data.csv` with it; the pipeline will adapt automatically.

## How to Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the full pipeline
```bash
python main.py
```

The script will:
- Generate/load the dataset.
- Run preprocessing and EDA.
- Train both models.
- Save all plots to `outputs/plots/`.
- Save metrics to `outputs/results/model_comparison.csv`.
- Save anomalies to `outputs/results/anomalies.csv`.
- Print the final conclusion.

---

## Results

Results are auto-generated when you run `main.py`.  
See `outputs/results/model_comparison.csv` and `outputs/results/final_conclusion.txt`.
